# Meowpick 重构版 · 用户视角

> 最后更新：2026-08-17

## 我打开 App 第一眼能看到什么？

**全部页面、所有交互都正常工作。** 没有"点开按钮没反应"、"页面突然空白"、"暗色模式半边白半边黑"这种让人皱眉的情况。

## 具体在哪些地方能感觉到用心

### 1. 一切动起来都很"顺"

- 几乎每一个页面加载时，**卡片像被推上桌一样**——首屏元素不是干巴巴地闪现，而是错落有致地依次出现（首页 0ms → 搜索框 60ms → 卡片 120ms → 180ms …）
- 按钮按下去**会缩小一下弹回来**——不是硬邦邦的"按下就触发"
- 页面切换时**全局用了 220ms 渐变**，不会突然"跳"
- 真正的"弹簧动画"——点赞时心形会跳跃而非只变色

### 2. 黑暗模式是"完整"的

不是"只换了背景色，加载状态还是白色"——**整个 App 真正做到了黑暗一致**：
- 卡片标题、内容、辅助文字、分割线、图标、阴影、提示框全部跟随
- 模态弹窗有滑入动画 + 背景遮罩
- 文字、图片、阴影**都不会刺眼或消失**
- 顶部导航栏和底部 Tab 都是**实色**面 + 阴影，扁平干净（不使用毛玻璃）

### 3. 真正节省时间的细节

- **首页搜索框**背景图 + 3 个功能卡片有 hover 反馈，按下有形变
- **提案页面**管理员/普通用户显示**不同 Tab**（管理员多看"操作记录"）
- **审批提案**可以跳到原表单再确认一遍细节（最终确认提案）
- **教师职称**独立显示（"张三 · 教授"），重名辨识时显示该老师最近 2 门课
- **每日配额**实时显示（"今日剩余 7/10"）——避免提交失败
- **30 天昵称冷却**避免反复修改

### 4. 真实有用的拒绝流程

管理员拒绝提案时：
1. 弹窗弹起（不是 native `showModal`）
2. 200 字内文本框有字数提示
3. 空内容时按钮自动禁用
4. 拒绝原因会**回传给提案提交者**看到

### 5. 反馈/通知总是有响应

- 加载中：圆形 spinner 旋转
- 加载失败：友好错误 + 重试按钮
- 空状态：emoji + 提示文字 + 行动按钮（如"快来发起第一个"）
- 提交成功：toast 提示 + 自动返回上一页

### 6. 用户的"耐心"被尊重

- 当我操作一个按钮时，不会出现"按钮没反应"——要么**有反馈**（toast/loading），要么**UI 有变化**（按钮按下、模态弹出）
- 关闭 modal 时遮罩渐隐 + 内容下滑，不会"砰"地消失
- 删完一条评论后列表立即更新，不需要刷新页面

---

## 用户可能不会注意到、但能感受到的细节

- 所有页面**都能横竖屏**切换内容布局
- 键盘弹起时输入框**自动滚动到可见区域**
- 触摸按钮时**不会有蓝色高亮**（移动端 -webkit-tap-highlight 已禁用）
- 减少动效开关打开时（系统设置）——所有动画立即停止
- 暗色模式下阅读更省眼（深灰 #1e1e1e，比纯黑 #000 减少对比度疲劳）
