# Meowpick 选课猫 — 前端设计语言

## 设计哲学

### 一、纯白画布 + 灰色色阶

主色调是**纯白**。白色是画布，灰色是画笔——所有层次感、远近关系、信息优先级都通过灰色色阶来表达，而非依赖品牌色。品牌色只在真正需要情感表达和用户注意力的地方出现。

- 页面底色用纯白或极浅中性灰，不用带色调的灰
- 灰色必须保持**中性**，不偏冷不偏暖，确保与纯白搭配时不产生色相冲突
- 同一组件的不同区域（如卡片内部的 header / body / footer）用不同灰度做层次，不用边框线分割

### 二、品牌色：纯色与渐变的节奏

品牌色是整个应用唯一的情感色。纯色和渐变交叉使用，节奏感在于：

- **纯色**用于信息层——文字强调、图标、徽标、状态指示。纯色表达的是"这件事很重要"
- **渐变**用于交互层——按钮、FAB、指示条、选中态。渐变表达的是"可以跟我互动"
- 两者的切换应自然，不突兀。同一个界面内纯色和渐变可以共存，但要服务于不同的语义

### 三、大 R 角是形状语言

圆角是 Meowpick 视觉上最显著的识别特征。整体偏向**大圆角**，但不是盲目地把所有东西都做成药丸形：

- **卡片、弹窗、Tab 栏**等大面积容器用大圆角，建立柔和的整体观感
- **按钮、胶囊、筛选 tag** 用 pill 形，是大圆角的极端表达
- **搜索框与下方内容的边界**这类细节处只需较小的圆角做过渡，避免生硬的直角即可，不需要追求大圆角
- 关键原则：**圆角大小与元素面积成正比**，小元素不需要大圆角

### 四、阴影做层次，发光做强调

**阴影**是层次系统的核心手段。任何需要与背景分离、表达"浮在上面"的元素都用阴影：

- 不同层级的元素用不同强度的阴影，形成视觉上的"海拔"
- 同一界面内，卡片、导航栏、浮层、模态各自有不同的阴影层级
- 阴影替代了大部分边框线——如果可以用阴影表达层次，就不用边框

**发光**（品牌色 box-shadow）只用于核心交互部件，且只用品牌红：
- 例如首页搜索框——它是整个应用最重要的入口，发光让它从周围跳出来
- 严格控制使用场景，不能滥用，否则会失去"发光 = 核心"的信号

### 五、丝滑且合乎逻辑的交互

动画不是装饰，是**空间叙事**——每一次动画都在回答"这个东西从哪来、到哪去"：

- 从下方出现的内容用上滑（如底部 Sheet）
- 在原地生长出来的用缩放（如居中弹窗）
- 从列表中逐个显现的用交错淡入
- 按压缩放、涟漪扩散是触觉反馈，不是视觉特效
- 如果动画没有传递有意义的信息，就去掉它
- 所有动画必须支持 `prefers-reduced-motion` 降级

### 六、悬浮设计 + 卡片设计 + 胶囊设计

这三者是 Meowpick 界面的骨架：

**悬浮设计**：所有使用阴影的元素都视为"悬浮"——导航栏、Tab 栏、FAB、卡片、弹出菜单。悬浮意味着它们不属于背景，而是独立存在于某个层级上。不同部件之间、不同颜色区域之间都用阴影做层次分隔，而不是靠颜色差异或线条。

**卡片设计**：内容以卡片为基本单元。卡片是悬浮设计的具体载体——白底 + 圆角 + 阴影，构成一个自包含的信息岛屿。不同类型的卡片（普通内容、提案、评论）通过微妙的背景色差和边框区分，但骨架结构保持一致。

**胶囊设计**：所有可交互的"按下去"的东西都用胶囊形（pill radius）。按钮、筛选 tag、搜索框、标签——胶囊是 Meowpick 的触觉签名。

**与微信系统胶囊对齐**：顶部导航栏在位置和视觉重量上与微信系统胶囊保持对称。底部 Tab 栏的筛选胶囊在水平位置上与系统胶囊形成呼应。这让应用感觉"长在微信里"而不是"套了个壳"。

## 暗色模式

暗色模式不是简单地反转颜色，而是用更深的灰色重新建立同样的层次关系：

- 页面和卡片各自使用更深层级的灰色，仍用灰色色阶做层次
- 品牌色保持不变，但阴影需要更高的不透明度才能在深色背景上可见
- 主题切换时所有颜色过渡要平滑，不能有跳变

## 无障碍

- 减弱动画偏好 (`prefers-reduced-motion`) 下所有动画禁用
- 语义状态色（成功/警告/危险/信息）覆盖所有需要语义区分的场景
