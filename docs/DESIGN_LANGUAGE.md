# Meowpick 选课猫 — 前端设计语言

## 设计哲学

### 一、纯白画布 + 灰色色阶

主色调是**纯白**。白色是画布，灰色是画笔——所有层次感、远近关系、信息优先级都通过灰色色阶来表达，而非依赖品牌色。品牌色只在真正需要情感表达和用户注意力的地方出现。

- 页面底色用纯白或极浅中性灰，不用带色调的灰
- 灰色必须保持**中性**，不偏冷不偏暖，确保与纯白搭配时不产生色相冲突
- 同一组件的不同区域（如卡片内部的 header / body / footer）用不同灰度做层次，不用边框线分割

### 二、品牌色：纯色与渐变的节奏

品牌色是整个应用唯一的情感色。纯色和渐变交叉使用，节奏感在于：

- **纯色**用于信息层——文字强调、图标、徽标、状态指示。纯色表达的是"这件事很重要"
- **渐变**用于交互层——按钮、FAB、指示条、选中态。渐变表达的是"可以跟我互动"
- 两者的切换应自然，不突兀。同一个界面内纯色和渐变可以共存，但要服务于不同的语义

### 三、大 R 角是形状语言

圆角是 Meowpick 视觉上最显著的识别特征。整体偏向**大圆角**，但不是盲目地把所有东西都做成药丸形：

- **卡片、弹窗、Tab 栏**等大面积容器用大圆角，建立柔和的整体观感
- **按钮、胶囊、筛选 tag** 用 pill 形，是大圆角的极端表达
- **搜索框与下方内容的边界**这类细节处只需较小的圆角做过渡，避免生硬的直角即可，不需要追求大圆角
- 关键原则：**圆角大小与元素面积成正比**，小元素不需要大圆角

### 四、阴影做层次，发光做强调

**阴影**是层次系统的核心手段。任何需要与背景分离、表达"浮在上面"的元素都用阴影：

- 不同层级的元素用不同强度的阴影，形成视觉上的"海拔"
- 同一界面内，卡片、导航栏、浮层、模态各自有不同的阴影层级
- 阴影替代了大部分边框线——如果可以用阴影表达层次，就不用边框

**发光**（品牌色 box-shadow）只用于核心交互部件，且只用品牌红：
- 例如首页搜索框——它是整个应用最重要的入口，发光让它从周围跳出来
- 严格控制使用场景，不能滥用，否则会失去"发光 = 核心"的信号

### 五、丝滑且合乎逻辑的交互

动画不是装饰，是**空间叙事**——每一次动画都在回答"这个东西从哪来、到哪去"：

- 从下方出现的内容用上滑（如底部 Sheet）
- 在原地生长出来的用缩放（如居中弹窗）
- 从列表中逐个显现的用交错淡入
- 按压缩放、涟漪扩散是触觉反馈，不是视觉特效
- 如果动画没有传递有意义的信息，就去掉它
- 所有动画必须支持 `prefers-reduced-motion` 降级

### 六、悬浮设计 + 卡片设计 + 胶囊设计

这三者是 Meowpick 界面的骨架：

**悬浮设计**：所有使用阴影的元素都视为"悬浮"——导航栏、Tab 栏、FAB、卡片、弹出菜单。悬浮意味着它们不属于背景，而是独立存在于某个层级上。不同部件之间、不同颜色区域之间都用阴影做层次分隔，而不是靠颜色差异或线条。

**卡片设计**：内容以卡片为基本单元。卡片是悬浮设计的具体载体——白底 + 圆角 + 阴影，构成一个自包含的信息岛屿。不同类型的卡片（普通内容、提案、评论）通过微妙的背景色差和边框区分，但骨架结构保持一致。

**胶囊设计**：所有可交互的"按下去"的东西都用胶囊形（pill radius）。按钮、筛选 tag、搜索框、标签——胶囊是 Meowpick 的触觉签名。

**与微信系统胶囊对齐**：顶部导航栏在位置和视觉重量上与微信系统胶囊保持对称。底部 Tab 栏的筛选胶囊在水平位置上与系统胶囊形成呼应。这让应用感觉"长在微信里"而不是"套了个壳"。

## 灰度色阶规范（Normative）

灰度是本设计系统的骨架。以下色阶为**唯一事实源**，任何页面不得再引入新的灰值；`_tokens.scss` 必须与此表一致。

### 亮色灰度阶

| Token | 值 | 用途 | 白底对比度 |
|---|---|---|---|
| `$bg-card-light` | `#ffffff` | 画布 / 卡片 / 弹窗 | — |
| `$bg-page-light` | `#f6f6f6` | 页面底色 | — |
| `$bg-muted-light` | `#efefef` | 内嵌区块 / 次级面 / 输入底 | — |
| `$divider-light` | `#e4e4e4` | 分割线 / 卡片描边 | — |
| `$border-color-strong-light` | `#cfcfcf` | 强调边框（输入、搜索框） | — |
| `$text-placeholder-light` | `#b0b0b0` | 占位符 | 2.1 |
| `$text-tertiary-light` | `#767676` | 辅助/说明文字 | **4.5 ✓** |
| `$text-secondary-light` | `#595959` | 次级正文 | 7.0 |
| `$text-primary-light` | `#1a1a1a` | 主文本 / 标题 | 16.9 |

规则：
- **必须中性**（R=G=B），不得出现偏蓝/偏冷灰（旧的 `#f7f8fa` 已废弃）。
- 相邻面之间的差异必须肉眼可辨：page 与 muted 至少相差 ~6 阶亮度，divider 不得与 muted 同值。
- 正文与辅助文字必须 ≥ 4.5:1；占位符允许更低但不得低于 ~2:1。

### 暗色灰度阶

| Token | 值 | 用途 |
|---|---|---|
| `$bg-page-dark` | `#121212` | 页面底色 |
| `$bg-card-dark` | `#1e1e1e` | 卡片 / 弹窗 |
| `$bg-muted-dark` | `#282828` | 内嵌区块 / 次级面 |
| `$bg-muted-darker` | `#333333` | 按压态 / 更深的次级面 |
| `$divider-dark` | `#333333` | 分割线 |
| `$divider-card-dark` | `#3d3d3d` | 卡片级细分割线（比全局分割线更亮一点以在卡上可见） |
| `$text-placeholder-dark` | `#6b6b6b` | 占位符 |
| `$text-tertiary-dark` | `#9a9a9a` | 辅助文字 |
| `$text-secondary-dark` | `#c4c4c4` | 次级正文 |
| `$text-primary-dark` | `#ededed` | 主文本 / 标题 |

规则：
- 暗色同样必须**中性**，且用“更深的灰”重建与亮色一致的层次，而非简单反转。
- 面与面的关系：page < card < muted，逐级变亮；分割线不得等于同层面值。

### 层次表达

- **面（surface）** 承担层次：page → card → muted 三级足够，不要发明第四级中间灰。
- **阴影**只用于“悬浮”部件（卡片、导航、FAB、模态、浮层），共 5 档：`$shadow-xs/sm/md/lg/xl`。禁止 one-off 阴影字面量。
- **边框**只用于“非悬浮”的细控件（输入框、tag），卡片优先用阴影而非 border；**不要同时用 border + 阴影**表达同一层次。

### 圆角规则

- 圆角与面积成正比：卡片 `$radius-xl(28rpx)`、内嵌块/输入 `$radius-md(16rpx)`、chip/tag `$radius-pill`、小图标 `$radius-xs/sm`。
- 禁止 `2vw`、`60rpx`、`24rpx` 这类脱离 token 的散值。

### 动效规则

- 时长只用 `$dur-*`（交互过渡）与 `$motion-*`（入场/弹入/循环）；曲线只用 5 条 `$ease-*`。
- 禁止 `transition: all`；只声明需要变化的属性。
- 列表错峰节奏统一为 **60ms**（`Math.min(index * 60, 300)`）。
- 所有可点击元素必须有按下反馈（`:active` 缩放或 `.mwp-pressable`），最小 `scale(0.97)`。
- 所有动效必须有 `prefers-reduced-motion` 降级。

### 装饰语言

装饰是品牌的“签名”，必须**同形同意**——同一种装饰在任何页面看起来都一样。统一实现为 `_mixins.scss` 中的 mixin + `_tokens.scss` 中的 `$deco-*`：

| 装饰 | Mixin | 用途 | 规格 |
|---|---|---|---|
| 标题强调条 | `@include title-accent` | 卡片/区块标题左侧 | 8rpx 竖直品牌渐变条 |
| 卡片高光线 | `@include card-top-line` | 卡片顶部，active/hover 显现 | 2rpx 居中品牌渐变 |
| 角落光晕 | `@include corner-glow($opacity)` | 品牌卡片右上角 | 200rpx 径向品牌光晕 |
| 引用块左条 | `@include quote-accent` | 说明/引用块 | 左侧 6rpx 品牌条 |
| 虚线分隔 | `@include dashed-divider` / `dashed-divider($deco-divider-dash-brand)` | 卡片内部区块分隔 | 1rpx dashed |
| 图标底板 | `@include icon-tile($size,$bg,$radius)` | 彩色圆角底包图标 | 默认 80rpx，色调用 `$tile-*` |
| 标签/徽标 | 直接 `border-radius: $radius-pill` | 状态、提案、新课等小标签 | 一律胶囊形 |

规则：
- 禁止再手写上述装饰（伪元素 / border-left 品牌条 / radial-gradient 光晕 / dashed 边框）；一律走 mixin。
- 颜色只用 `$deco-*` 或品牌 token，不得出现新的一次性 rgba。
- 装饰只为强调层级与品牌识别服务，同一容器内不超过两种装饰。

### 采用规则

- 通用组件（`Button / EmptyState / StatusBadge / SkeletonCard`）为唯一实现；页面不得再手写等价结构。
- 不允许 `<button>`（小程序默认样式无法覆盖）；交互元素用 `<view class="mwp-pressable">` 或 `Button`。
- 暗色模式统一用 `.dark-theme &` 嵌套；禁止全局 `<style>` 覆盖块与 `!important`。

## 暗色模式

暗色模式不是简单地反转颜色，而是用更深的灰色重新建立同样的层次关系：

- 页面和卡片各自使用更深层级的灰色，仍用灰色色阶做层次
- 品牌色保持不变，但阴影需要更高的不透明度才能在深色背景上可见
- 主题切换时所有颜色过渡要平滑，不能有跳变

## 无障碍

- 减弱动画偏好 (`prefers-reduced-motion`) 下所有动画禁用
- 语义状态色（成功/警告/危险/信息）覆盖所有需要语义区分的场景
